# GRIMLIGHT: The Hollow Bell — Level Passcodes

Stuck, or reviewing? Jump to any level from the title screen (SELECT) with these codes. Enter a room's 5-letter code and press A/START — a wrong code just gets you "THE BELL STAYS SILENT" and nothing changes. Every room's intro screen also shows its own code, so you can always pick up right where you left off.
